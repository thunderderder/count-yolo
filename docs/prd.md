# PRD — count_yolo

## 目标

把固定机位交叉口录像，变成交通调查表能用的「进口 × 转向 × 车型」辆次。使用者是做交通调查的工程师，不是要买一个检测 SaaS 的客户。成功标准是同一段视频可以重复跑、误差可对照人工表解释，而不是界面或部署。

## 用户与场景

主用户自己跑脚本。输入是 MP4 + 一份路口标定。输出是 JSON，以后再写入 Excel 模板。流量示意图由既有 Excel 模板生成，本项目只负责把数填对。

典型约束：一台高位摄像头同时看多个方向；路口不一定是标准十字；视频经常远、暗、有桥墩遮挡。

## 需求

1. L1：近场画一条线，按方向过滤后统计单向通过辆次，并映射到摩托 / 大货 / 小货公交 / 小车。
2. 与人工调查表按验收层级比对，默认 L1 合计误差 ±15%。
3. L3：entry/exit 多边形 + 右侧通行转向表。作为后续能力保留骨架，不作为本阶段交付。
4. 标定工具可在本机窗口画线。无 GUI 时回退 matplotlib。

明确不做：模型训练、多机位拼接、Web、云端部署、pcu 换算、示意图绘制。

## 成功标准

- 离线单测在无 GPU、无视频时通过。
- 示例视频 L1 可用 yolov8m 复现南直行约 1304（对照 1533，-14.9%），并能解释摩托漏检。
- 公开仓库不含视频、权重、本机绝对路径和真实密钥。

## 非目标

不把这个仓库写成 CV 代表作。它是调查流程里的赋能脚本，证据在分层验收和一次结果级拼接，不在「用了 YOLO」。
